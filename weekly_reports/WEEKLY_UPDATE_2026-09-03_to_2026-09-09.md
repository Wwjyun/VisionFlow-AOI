## 版本差異與風險

- `utility-tools-v1.1.0` annotated tag 實際指向 `283929b`，而互動式儀表板提交 `2db2186` 發生在 tag 之後；因此 tag 所對應的 repository source 不包含後續儀表板升級，不能把兩者視為同一版來源。GitHub Release 另有稍後上傳的 `Tile-Defect-Distribution-Exporter.zip`，但仍應以明確 commit、資產 digest 與發行說明維持可追溯性。
- Utility Tools v1.1.0 為 Windows 10／11 x64、CPU-only、未簽章工具；Windows SmartScreen 可能顯示未知發行者。Plotly 已內嵌以供離線使用，但大型輸入資料的長時間穩定性與實際產線瀏覽器效能仍需以真實資料驗證。
- 儀表板的 Tile NG 率需要同次輸出的完整 JSON 作為檢測次數分母；只有 `summary.csv`、JSON 缺失或損壞時會停用 NG 率，不能將缺陷筆數或空白 Tile 推論為檢測良率。
- 本週功能不變更 AOI Pipeline、Detector 或 CUDA ABI；AOI `v1.5.1` 的 RTX 3090 合成驗證結論不因此擴張為真實產線 acceptance。
